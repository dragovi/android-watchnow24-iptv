# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/9e4d372b-748b-4668-9d15-b88d402aadeb

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Features

- **Live TV**: High-definition satellite feeds.
- **VOD & Series**: Extensive library of movies and episodic content.
- **AI Assistant**: Powered by Google Gemini, get recommendations and help directly in the app.
- **Integrated VPN**: Secure your connection with simulated geo-nodes.
- **Speed Test**: Verify your bandwidth for optimal streaming.
- **Parental Control**: Secure categories with a PIN.
- **Multi-Screen**: Watch two streams simultaneously.
